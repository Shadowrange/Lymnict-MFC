# Lymnict-MFC - умный поиск ответов по базе МФЦ

Хакатонный проект команды **Lymnict** (август 2023). Роль: **тимлид** - [Shadowrange](https://github.com/Shadowrange).

После хакатона команда сотрудничала с МФЦ по развитию решения.

Система вопрос-ответ: пользователь пишет вопрос своими словами - система находит ближайший вопрос в базе знаний и выдаёт ответ.

**Как работает**
- Ранжирование кандидатов - **BM25** (`rank_bm25`) по базе вопросов/ответов
- Морфологический анализ русского языка - **pymorphy2**: отсекаются служебные части речи, фильтруются несуществующие слова
- Десктоп-интерфейс на **PySimpleGUI**, база знаний - Excel (pandas)

**Стек:** Python, pandas, NumPy, rank_bm25, pymorphy2, PySimpleGUI
